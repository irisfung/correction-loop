# Correction Loop - Document Extraction Workflow

A web application for document extraction workflow featuring an interactive interface for viewing documents, configuring extraction schemas, and managing results.

## Project Structure

```
correction-loop/
├── index.html          # Main HTML file
├── css/
│   └── styles.css     # All styles and design system
├── js/
│   └── app.js         # Application logic and interactions
└── README.md
```

## Features

- Document viewer with navigation
- Interactive schema configuration
- Results visualization
- Batch processing support
- Audit and correction tracking

## Getting Started

Simply open `index.html` in a modern web browser to run the application.

## Technology

- Pure HTML, CSS, and JavaScript
- No build process required
- Responsive design with CSS Grid and Flexbox
